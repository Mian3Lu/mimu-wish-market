# mimu. 愿望市集

> **写下一个愿望，等待一次温柔的接单。**  
> 一个以「主题美化 / 世界书 / App / 心声」等创作需求为核心的匿名许愿与创作者接单社区。/

![mimu 愿望市集移动端预览](assets/previews/market-mobile.webp)

**当前开发主线：小红书市集风格（`index.html`）**。奶油手帐版、INS 杂志版以及旧版市集均保留在 [`archive/`](archive/) 中，不覆盖、不删除。根目录 `index.html` 已加入 Supabase Auth 与数据读写的接入尝试，但尚未完成安全验收，不能视为可公开运营的多人版本。

## ✦ 项目定位

用户发布创作愿望，创作者自愿接单、留言沟通、更新制作进度；完成后在原帖标注统一资源库中的文件位置或领取链接。**作品文件统一存放在外部资源库**，网站本身不是资源上传/下载仓库，也没有独立的 Repo 反馈区。

**完整流程：**

`发布愿望 →（最多 3 位创作者独立接单）→ 正在制作 → 已完成 → 附上文件位置 / URL`

### 完成后的文件位置提示

在创作者将接单状态标为「已完成」时，位置输入框内提供以下候选：

`仓库群1` · `仓库群2` · `Aaa我不是饭神` · `Bbb我不是饭神` · `discord`

以上是输入建议，**也允许自行填写其他位置**；若有可直接领取的网页地址，可另外填写 URL。网站只记录领取位置，不代替资源库托管文件。

## ✦ 本地运行

无需安装构建依赖。页面从 CDN 加载 Supabase JS，并使用项目 URL 与 publishable key；登录和云端数据需要网络可用，匿名登录还需在 Supabase Auth 中启用。可用本地 HTTP 服务预览。

如果希望使用本地 HTTP 服务（推荐用于测试）：

```bash
# 在项目根目录执行
python3 -m http.server 5500
```

然后打开 <http://localhost:5500/>。无需 Node.js、npm 或后端进程；页面脚本仍需联网加载 Supabase 客户端和访问项目。

> 注意：帖子、接单、留言、点赞和举报已有云端读写尝试；昵称、主题及收藏仍保存在本地浏览器。图片上传目前走公开 bucket，隐藏接单图片不具备数据库级隐私保护。

### Supabase 接入状态

Supabase 项目已创建表、RLS 策略和公开图片 bucket；当前页面仍有待修复的数据库隐私与管理审计问题。请先按 [`supabase/README.md`](supabase/README.md) 核验迁移，并通过 RLS 与 Storage 权限测试后再部署。浏览器只使用 Supabase publishable key；它不是管理员身份凭据。

### 管理员与安全提醒

页面管理员入口使用 Supabase 邮箱密码登录，并查询 `admin_roles`。是否允许管理操作最终由数据库策略决定；当前项目的策略和隐藏接单数据访问仍有问题。

- 接单隐藏状态目前主要靠页面过滤；数据库仍允许公开读取完整接单行。
- 图片位于公开 bucket，持有对象 URL 的人可直接访问。
- 管理员的留言/接单删除尚未统一改为可恢复软删除，管理操作审计也未完整接入。
- **完成 RLS、Storage 私有访问、接单并发约束、软删除及审计 migration 前，不要作为公开社区上线。**

### 部署前必须注意

GitHub 的 **Private 仓库不会让已经部署到浏览器里的 HTML / JS 保密**。Supabase 的 publishable / anon key 可供浏览器使用，但必须设置 RLS；**数据库密码、service_role / secret key、管理员密钥绝不能提交到 Git 或放进前端**。

本仓库目前只包含静态 HTML；当前 Supabase 接入仍在开发中，必须先修复权限与数据结构，再替换剩余本地存储逻辑，避免简单地把前端变量同步到数据库后造成越权。
